# Модуль Tags

Система тегов для произведений искусства.

## 📋 Описание

CRUD для тегов и привязка тегов к артам.

## 🔑 Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `tags.controller.ts` | HTTP-контроллер |
| `tags.service.ts` | Бизнес-логика |
| `tag.model.ts` | Модель Tag |
| `art-tag.model.ts` | Модель ArtTag (связь арт-тег) |

## ⚙️ Особенности

- Теги могут быть привязаны к произведениям искусства
- Поддержка поиска и фильтрации по тегам

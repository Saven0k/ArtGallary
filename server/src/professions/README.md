## Модуль профессий (Professions)
### Модуль для управления профессиями с базовым CRUD.

#### ├── professions.controller.ts    # Контроллер
#### ├── professions.module.ts        # Модуль
#### └── dto/
####     ├── create-profession.dto.ts
####     └── update-profession.dto.ts


## API
Метод	Эндпоинт	Описание
POST	/professions	Создать
PUT	/professions/:id	Обновить
DELETE	/professions/:id	Удалить
GET	/professions	Все
GET	/professions/:id	По ID

## Автоматическое заполнение

При каждом запуске сервера модуль добавляет отсутствующие базовые профессии: художник, скульптор, фотограф, графический дизайнер, иллюстратор, архитектор, керамист, реставратор и художник по костюмам. Каждая запись содержит название и описание.

Существующие записи, их ID и описания сохраняются. Повторный запуск не создаёт дубли. Удалённая базовая профессия появится снова при следующем запуске. Дополнительные профессии остаются в таблице.

Отдельные команды и настройки окружения не нужны. Существующий административный `POST /professions/seed` использует тот же механизм. При ошибке заполнения запуск сервера завершается с ошибкой, чтобы пустой справочник не выдавался за успешно подготовленный.

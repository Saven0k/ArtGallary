# Цена и валюта картины

`arts.cost` хранит сумму, `arts.currency` — валюту автора. Для создания и изменения доступны только `RUB`, `USD`, `CNY`. Цена неотрицательная, максимум два знака после запятой; отсутствие цены передаётся как `null`. Создание принимает multipart (`cost=1500.50`, `currency=CNY`), изменение — JSON (`{"cost":1500.5,"currency":"CNY"}`). Поля уже существуют в БД: миграция для этого изменения не нужна.

GET-запросы `/arts/...` и `/authors/...` добавляют к картинам поле `display_price` в зависимости от `lang`: `ru` → RUB, `en` → USD, `zh` → CNY. Работают и варианты `en-US`, `zh-CN`. Исходные `cost` и `currency` не меняются. Пример ответа для `?lang=en`:

```json
{
  "cost": 8000,
  "currency": "RUB",
  "display_price": {
    "amount": 100,
    "currency": "USD",
    "rate": 0.0125,
    "rate_date": "2026-10-20"
  }
}
```

Курс в примере условный. Сервер бесплатно получает официальные ежедневные курсы [Банка России](https://www.cbr.ru/development/sxml/) из `https://www.cbr.ru/scripts/XML_daily.asp`. API-ключи, отдельный контейнер и настройки не нужны. Формула: исходная сумма × (рубли за единицу исходной валюты / рубли за единицу целевой валюты). Номинал валюты учитывается, результат округляется до двух знаков. Это справочный официальный курс, не курс конкретного банка или платёжной системы.

Курсы загружаются при старте и обновляются по запросу не чаще раза в час. Параллельные запросы используют одну загрузку; время ожидания ограничено четырьмя секундами. При сбое повторная попытка выполняется не раньше чем через минуту. Последний курс можно использовать до семи дней (включая выходные); более старые данные не используются. Если актуального курса нет, `display_price` отсутствует: интерфейс показывает исходную цену с её настоящей валютой. Цена без пересчёта имеет `rate=1`, `rate_date=null`. При переключении языка фронт заново запрашивает данные с `lang`.

Фронт показывает пересчёт со знаком `≈`. Каталог, карточка работы, работы автора, избранное и корзина используют `display_price`. Корзина отдельно указывает сумму в исходной валюте автора, в которой оформляется заказ. Расчёт и история заказов используют сохранённые исходные цены; существующие проверки количества, промокодов и смешанных валют сохраняются.

`?original=true` отключает пересчёт для редактирования. POST/PATCH возвращают исходные цены. Автоматическая конвертация не зависит от настройки перевода текстов `TRANSLATION_ENABLED`. Старые EUR/UAH записи не удаляются и не переименовываются: их можно показать по курсу ЦБ, но при изменении цены в форме нужно явно выбрать одну из трёх поддерживаемых валют. История уже оформленных заказов не пересчитывается.

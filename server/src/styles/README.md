#  Модуль стилей (Styles Module)

> Модуль для управления художественными стилями в приложении. Предоставляет полный CRUD-функционал для создания, чтения, обновления и удаления стилей.

###  Структура проекта

```text
src/styles/
├── dto/
│   ├── create-style.dto.ts    # DTO для валидации данных при создании
│   └── update-style.dto.ts    # DTO для валидации данных при обновлении
├── styles.controller.ts       # Обработка HTTP-запросов (API эндпоинты)
├── styles.model.ts            # Модель данных (Entity / Interface)
├── styles.module.ts           # Конфигурация и подключение модуля
└── styles.service.ts          # Бизнес-логика и работа с данными

```
###  Модель данных

```typescript 
interface Style {
  id: number;             // Уникальный идентификатор
  name: string;           // Название стиля (уникальное, обязательное)
  description?: string;   // Описание стиля (необязательное)
}
```


### API Эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/styles` | Создать новый стиль |
| `GET` | `/styles` | Получить список всех стилей |
| `GET` | `/styles/:id` | Получить конкретный стиль по ID |
| `PUT` | `/styles/:id` | Обновить существующий стиль |
| `DELETE` | `/styles/:id` | Удалить стиль по ID |
